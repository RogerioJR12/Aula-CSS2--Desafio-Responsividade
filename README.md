<h1 >  🐾 We Care About Your Pet  </h1>

<p>  Este projeto consiste no desenvolvimento de uma Landing Page para um site voltado ao cuidado e bem-estar dos animais de estimação.  </p>

<p>  A proposta foi criar uma interface moderna, visualmente agradável e intuitiva, utilizando HTML e CSS, com foco na construção de um layout responsivo.  </p>

<h3>  🎨 Sobre o projeto  </h3>

<p>  A página apresenta:

Menu de navegação com opções Home, About, Product, Service e Contact.<br>
Botão de Login.<br>
Seção principal com o título "We Care About Your Pet".<br>
Ilustração relacionada ao cuidado com animais.<br>
Botão Explore.<br>
Layout com foco em responsividade.  </p>

<h4>  📱 Responsividade  </h4>

<p>  O projeto foi desenvolvido como um desafio prático para trabalhar conceitos de CSS e adaptação de layouts para diferentes tamanhos de tela.  </p>

<h5>  🎯 Objetivo  </h5>

<p>  Colocar em prática os conhecimentos adquiridos em HTML e CSS, desenvolvendo uma página web com organização visual, estilização e responsividade.  </p>
